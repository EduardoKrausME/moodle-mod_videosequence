# Video Sequence (mod_videosequence)

Video Sequence is a Moodle activity for learning processes, procedures, and ordered events from video. Students watch a
configured video and then either reorder teacher-defined steps or reconstruct the sequence from memory.

Features include uploaded video, direct video URL, YouTube and Vimeo sources; server-side watched-progress tracking;
resume playback; optional anti-skip behavior; minimum watched percentage before answering; step-linked timestamps;
drag-and-drop ordering with keyboard-friendly move controls; student-created sequences with accepted aliases; attempt
limits; immediate or final feedback; automatic grading; Moodle completion rules; teacher reports; backup/restore;
Privacy API support; and English/Portuguese (Brazil) language packs.

After creating the activity, use “Manage sequence” to add the reference steps in their correct order. Each step may
include a description, accepted alternative names, and a video start/end time. In reorder mode students receive those
steps shuffled. In create mode the reference names are hidden and students type the sequence.

Requires Moodle 4.4 or newer.
